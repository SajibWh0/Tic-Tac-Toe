# Neon Tic Tac Toe 🎮✨

A modern, visually stunning Tic Tac Toe game built with HTML, CSS, and Vanilla JavaScript. Featuring a sleek dark mode aesthetic, smooth glassmorphism effects, and vibrant neon glow animations that make the classic game feel entirely new.

## ✨ Features

- **Neon Aesthetic:** High-contrast glowing elements and sleek typography.
- **Glassmorphism UI:** Modern translucent game board overlaying dynamic background animations.
- **Smooth Animations:** Satisfying "pop-in" animations for markers (X & O) and hover effects.
- **Dynamic Win Highlighting:** Visually distinct glowing effects for winning combinations.
- **Responsive Design:** Completely playable on both desktop and mobile devices.

## 🛠️ Tech Stack

- **HTML5** - For semantic structure
- **CSS3** - For styling, animations, and neon/glassmorphism effects
- **Vanilla JavaScript** - For game logic and DOM manipulation

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/neon-tic-tac-toe.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd neon-tic-tac-toe
   ```
3. **Open the game:**
   Simply open `index.html` in your favorite web browser.
   *(No build tools or server required!)*

## 🎮 How to Play

1. Player `X` always goes first.
2. Click any empty cell to place your marker.
3. The game will automatically detect a win (3-in-a-row horizontally, vertically, or diagonally) or a draw.
4. Click the **RESET GAME** button to play again!
